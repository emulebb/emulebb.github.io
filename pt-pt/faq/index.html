Perguntas comuns sobre eMule, respondidas para o eMuleBB

Respostas curtas para quem quer o fluxo clássico do eMule com melhor controlo de banda larga, rede mais segura e provas de release mais claras.

Como ligo o eMule a uma interface ou VPN?

O eMuleBB pode vincular o tráfego P2P a uma interface ou endereço local e bloquear o arranque se o destino faltar. Mantenha o kill switch da VPN, a firewall e o bind do WebServer/REST separados.

Saber mais: Guia de rede

Como partilho a minha biblioteca no eMule?

O eMuleBB mantém o modelo Shared Files: adicione raízes selecionadas, mantenha a Temp fora das partilhas, use caminhos estáveis e deixe o hashing terminar antes de crescer.

Saber mais: Guia de partilha

Como limito os slots de upload no eMule?

O eMuleBB acrescenta um alvo finito de slots de upload em banda larga, reciclagem de slots fracos e diagnósticos práticos para que ligações rápidas continuem úteis sem inundar a fila.

Saber mais: Guia de transferências e pesquisa

O eMuleBB é um fork de protocolo do eMule?

Não. O eMuleBB mantém o comportamento eD2K e Kad compatível com o stock por omissão e melhora os limites locais, a automação, os diagnósticos e a disciplina de release à sua volta.

Saber mais: Guia do produto

Que release do eMule devo usar para testar?

Use a release do GitHub eMuleBB 0.7.3-rc.3 publicada para os testes RC. O alvo estável continua a ser 0.7.3 depois de passarem os gates.

Saber mais: Painel de release 0.7.3

Como mantenho o WebServer ou o REST do eMule seguros?

O eMuleBB trata o WebServer e o REST como superfícies para controladores de confiança. Ative-os apenas quando necessário, faça bind deliberadamente, use uma API key e evite exposição ampla.

Saber mais: Guia de controladores e REST

Como uso o eMule com Kad e servidores?

O eMuleBB mantém os fluxos clássicos de servidor, pesquisa global e Kad. Comece com listas de servidores de confiança, faça bootstrap do Kad deliberadamente e diagnostique Low ID ou Kad com firewall antes de mudar muitas opções.

Saber mais: Guia de rede

Como lido com grandes bibliotecas partilhadas no eMule?

O eMuleBB foi feito para grandes bibliotecas: adicione raízes gradualmente, use Windows com long paths, reveja as regras de share-ignore e deixe a cache de arranque assentar.

Saber mais: Guia de partilha

Posso automatizar o eMule com ferramentas externas?

Sim. O eMuleBB expõe uma REST API JSON autenticada para controladores locais de confiança, mantendo a semântica nativa de transferências e partilha na aplicação de ambiente de trabalho.
