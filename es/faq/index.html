FAQ

Preguntas comunes de eMule, respondidas para eMuleBB

Respuestas breves para usar el flujo clasico de eMule con mejor control de banda ancha, red mas segura y pruebas de release claras.

Como vinculo eMule a una interfaz o VPN?

eMuleBB puede vincular el trafico P2P a una interfaz o direccion local y bloquear el arranque si falta el destino. Mantén aparte el kill switch VPN, firewall y bind de WebServer/REST.

Leer mas: Guia de red

Como comparto mi biblioteca en eMule?

eMuleBB conserva el modelo Shared Files: agrega raices cuidadas, deja Temp fuera de las compartidas, usa rutas estables y espera a que termine el hashing.

Leer mas: Guia de comparticion

Como limito los slots de subida en eMule?

eMuleBB agrega un objetivo finito de slots de subida, reciclaje de slots debiles y diagnostico practico para aprovechar lineas rapidas sin inundar la cola.

Leer mas: Guia de descargas y busqueda

eMuleBB es un fork de protocolo de eMule?

No. eMuleBB mantiene eD2K y Kad compatibles con el comportamiento stock, y mejora limites locales, automatizacion, diagnostico y disciplina de release.

Leer mas: Guia del producto

Que release de eMule debo usar para pruebas?

Usa la release GitHub eMuleBB 0.7.3-rc.1 publicada para pruebas RC. El objetivo estable sigue siendo 0.7.3 despues de pasar los gates.

Leer mas: Panel de release 0.7.3

Como mantengo seguro WebServer o REST de eMule?

eMuleBB trata WebServer y REST como superficies para controladores confiables. Activalos solo cuando haga falta, configura el bind, usa API key y evita exponerlos ampliamente.

Leer mas: Guia de controladores y REST

Como uso eMule con Kad y servidores?

eMuleBB conserva servidores, busqueda global y Kad. Empieza con listas confiables, arranca Kad con cuidado y diagnostica Low ID o Kad firewalled antes de tocar muchas opciones.

Leer mas: Guia de red

Como manejo bibliotecas compartidas grandes en eMule?

eMuleBB esta preparado para bibliotecas grandes: agrega raices gradualmente, usa Windows con long paths, revisa share-ignore y deja asentarse la cache de inicio.

Leer mas: Guia de comparticion

Puedo automatizar eMule con herramientas externas?

Si. eMuleBB ofrece una REST API JSON autenticada para controladores locales confiables, manteniendo la semantica nativa de transferencias y comparticion en la app desktop.
