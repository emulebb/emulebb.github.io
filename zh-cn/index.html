Stable MFC capabilities

What the maintained MFC client already provides

These are shipped 0.7.3 capabilities, not a promise of renewed broad MFC development. Maintenance remains compatibility- and risk-bounded.

共享与上传

宽带上传控制

有界的槽位目标、弱槽回收、分享率读数和做种控制，在不改变 eD2K 上传协议的前提下让高速上传链路保持有用。

网络控制

Binding、NAT 与暴露策略

感知接口的 binding、UPnP/NAT 映射校验、HTTPS、允许 IP 规则以及独立的 WebServer 绑定设置，使远程入口保持显式且可测试。Binding 不是 VPN 终止开关。

性能与规模

面向大型会话的现代默认值

更大的套接字缓冲区、队列/来源限制、文件缓冲、超时默认值、递归共享同步、启动缓存处理和长路径指引，针对当前的 Windows 系统和大型库。

经典网络

eD2K 和 Kad 仍居首位

服务器、全局和 Kad 搜索仍是原生基础，Kad 身份跟踪、坏节点处理、清理和计时工作都保持在兼容边界之内。

自动化

REST 与控制器工作流

经过认证的 JSON 端点涵盖传输、搜索、共享文件、服务器、Kad、日志、分类、上传、统计、首选项以及来自受信任本地工具的受控关闭。

测试与发布纪律

先有证据，后有标签

0.7.3 发布时附带 GitHub Actions 打包、清单、SHA-256 证据、SPDX SBOM、诊断资源以及引导程序哈希证据。

Published releases

Use the release that matches the lane

Rust nightly builds

CI-passed main commits publish immutable nightly prereleases with native packages, SHA256SUMS, provenance attestations, and a retained history of the newest 14 builds.

MFC 0.7.3

The stable Windows package remains published with manifests, hashes, SBOMs, and diagnostics assets.

Historical Suite bundle

The MFC 0.7.3 release keeps its suite installer and aMuTorrent artifact. “Suite” describes that shipped bundle, not an active umbrella roadmap.

Evidence stays lane-specific

Capabilities, platform support, and network-safety claims must be proven by the repository and release that owns them.
