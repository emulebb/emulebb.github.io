FAQ

Perguntas comuns sobre eMule, respondidas para eMuleBB

Respostas curtas para usar o fluxo classico do eMule com melhor controle de banda larga, rede mais segura e provas de release claras.

Como vinculo o eMule a uma interface ou VPN?

O eMuleBB pode vincular o trafego P2P a uma interface ou endereco local e bloquear a inicializacao quando o alvo falta. Mantenha kill switch VPN, firewall e bind WebServer/REST separados.

Leia mais: Guia de rede

Como compartilho minha biblioteca no eMule?

O eMuleBB mantem o modelo Shared Files: adicione raizes selecionadas, deixe Temp fora do compartilhamento, use caminhos estaveis e espere o hashing terminar.

Leia mais: Guia de compartilhamento

Como limito os slots de upload no eMule?

O eMuleBB adiciona alvo finito de slots de upload, reciclagem de slots fracos e diagnosticos praticos para aproveitar links rapidos sem lotar a fila.

Leia mais: Guia de downloads e busca

O eMuleBB e um fork de protocolo do eMule?

Nao. O eMuleBB mantem eD2K e Kad compativeis com o comportamento stock e melhora limites locais, automacao, diagnosticos e disciplina de release.

Leia mais: Guia do produto

Qual release do eMule devo usar para testes?

Use a release GitHub eMuleBB 0.7.3-rc.2 publicada para testes RC. O alvo estavel continua sendo 0.7.3 depois que os gates passarem.

Leia mais: Painel da release 0.7.3

Como mantenho seguros WebServer ou REST do eMule?

O eMuleBB trata WebServer e REST como superficies para controladores confiaveis. Ative apenas quando precisar, configure bind, use API key e evite exposicao ampla.

Leia mais: Guia de controladores e REST

Como uso eMule com Kad e servidores?

O eMuleBB mantem servidores, busca global e Kad. Comece com listas confiaveis, inicialize Kad com cuidado e diagnostique Low ID ou Kad firewalled antes de mudar muita coisa.

Leia mais: Guia de rede

Como lidar com grandes bibliotecas compartilhadas no eMule?

O eMuleBB foi feito para bibliotecas grandes: adicione raizes aos poucos, use Windows com long paths, revise share-ignore e deixe a cache de inicio estabilizar.

Leia mais: Guia de compartilhamento

Posso automatizar o eMule com ferramentas externas?

Sim. O eMuleBB expoe uma REST API JSON autenticada para controladores locais confiaveis, mantendo a semantica nativa de transferencias e compartilhamento no app desktop.
