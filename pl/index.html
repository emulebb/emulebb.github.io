Stable MFC capabilities

What the maintained MFC client already provides

These are shipped 0.7.3 capabilities, not a promise of renewed broad MFC development. Maintenance remains compatibility- and risk-bounded.

Udostępnianie i upload

Szerokopasmowa kontrola uploadu

Ograniczone cele slotów, recykling słabych slotów, odczyty ratio i sterowanie seedowaniem utrzymują przydatność szybkich łączy uploadu bez zmiany protokołu uploadu eD2K.

Kontrola sieci

Binding, NAT i polityka ekspozycji

Binding świadomy interfejsu, walidacja mapowania UPnP/NAT, HTTPS, reguły dozwolonych IP i osobne ustawienia bindowania WebServera utrzymują zdalne powierzchnie jawnymi i testowalnymi. Binding to nie kill switch VPN.

Wydajność i skala

Nowoczesne wartości domyślne dla dużych sesji

Większe bufory gniazd, limity queue/source, buforowanie plików, domyślne timeouty, rekurencyjna synchronizacja udziałów, praca cache startowego i wskazówki dotyczące długich ścieżek celują w obecne systemy Windows i duże biblioteki.

Klasyczna sieć

eD2K i Kad pozostają na pierwszym miejscu

Wyszukiwanie Server, globalne i Kad pozostaje natywną podstawą, z śledzeniem tożsamości Kad, obsługą złych węzłów, czyszczeniem i pracą nad timingiem w granicach zgodności.

Automatyzacja

Przepływy REST i kontrolerów

Uwierzytelnione endpointy JSON obejmują transfery, wyszukiwania, udostępniane pliki, serwery, Kad, logi, kategorie, uploady, statystyki, preferencje i kontrolowane zamykanie z zaufanych narzędzi lokalnych.

Published releases

Use the release that matches the lane

Rust nightly builds

CI-passed main commits publish immutable nightly prereleases with native packages, SHA256SUMS, provenance attestations, and a retained history of the newest 14 builds.

MFC 0.7.3

Version 0.7.3 remains published while the 0.7.x line provides diagnostics, critical fixes, and bounded maintenance. Published packages retain manifests, hashes, SBOMs, and diagnostics assets.

Historical Suite bundle

The MFC 0.7.3 release preserves the historical Suite installer and matching aMuTorrent artifact. Suite is a shipped bundle name, not an active cross-client roadmap.

Evidence stays lane-specific

Capabilities, platform support, and network-safety claims must be proven by the repository and release that owns them.
